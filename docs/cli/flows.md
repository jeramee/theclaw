# `theclaw tasks flow`

Flow commands are subcommands of `theclaw tasks`, not a standalone `flows` command.

```bash
theclaw tasks flow list [--json]
theclaw tasks flow show <lookup>
theclaw tasks flow cancel <lookup>
```

For full documentation see [Task Flow](/automation/taskflow) and the [tasks CLI reference](/cli/tasks).
